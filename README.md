# МедПраво — публикации для центра «Евромед» в Калуге

Сайт: [levshamv.github.io/medpravo](https://levshamv.github.io/medpravo/). Инструкция находится в разделе «Как пользоваться» на самом сайте.

Федеральные и местные документы по работе медицинского центра: ОМС, МРТ/КТ, дети, наркоз, дневной стационар, забор анализов и общие требования к медицинской организации и работодателю. Письма, проекты, тарифные соглашения и клинические рекомендации имеют собственные категории и не выдаются за новые законы. Платные базы и API ChatGPT не используются.

## Добавление и хранение документов

Лента содержит только документы с подтверждённой датой публикации **с 1 октября 2026 года включительно**. Более ранние и недатированные записи удаляются из публикуемой ленты и текущего сохранённого состояния; при последующем сборе не добавляются. Дата принятия акта, вступления в силу, дата файла и время обнаружения не заменяют дату публикации. При противоречивых датах запись не добавляется.

Для записей, прошедших этот порог, срок хранения и предел количества сейчас не заданы. Один URL не создаёт повторную публикацию. Собираются отдельные новые акты о внесении изменений; замена содержимого старого файла по прежнему URL не отслеживается. История Git может сохранять прежние версии состояния.

Дата берётся из явного поля карточки, страницы или API официального источника. «Как подтверждена дата» в карточке показывает основание и ссылку. PDF с текстовым слоем и DOCX обрабатываются с ограничениями: до 20 МБ на файл, первые 30 страниц PDF, до 60 000 символов в сохранённом тексте и до 6 000 в публичном фрагменте. PDF-сканы отмечаются как требующие распознавания; OCR пока не подключён. Архивы ZIP/RAR и защищённые файлы не распаковываются для чтения. Текст помогает отбору, но результат не является юридическим заключением.

По умолчанию показана подборка «По темам центра». Варианты «Проверить вручную» и «Все собранные документы» доступны в фильтре. Отбор учитывает заголовок и доступный извлечённый текст; название ведомства само по себе не считается медицинской темой. Исходный заголовок, основание отбора и качество текста можно раскрыть в карточке. Отметки просмотра хранятся только в текущем браузере.

## Обновление и время последнего сбора

GitHub Actions запускает сбор примерно в **03:17, 09:17, 15:17 и 21:17 по Москве**. GitHub может задержать или пропустить плановый запуск. После длительного отсутствия активности расписание публичного репозитория может отключиться: проверяйте Actions.

Блок «Последний завершённый сбор» показывает фактическое время завершения последней проверки источников по Москве, включая секунды. Это не время открытия сайта и не дата самого нового документа. Новый сбор может не найти новых подходящих публикаций. Обновление открытой страницы каждые 30 секунд только получает уже опубликованную ленту.

Ручной сбор: «Запустить на GitHub» → **Run workflow** → **Run workflow**. Нужен вход в аккаунт владельца. Для сбора свежих документов оставьте «Только переопубликовать» выключенным. После успешного окончания откройте или обновите сайт. Компьютер владельца и Docker для опубликованной версии не нужны.

## Источники и доступ

В sources.json 26 источников, 22 включены. Четыре дополнительных раздела выключены до настройки адаптеров или доступа. Сборщик читает настроенные открытые разделы; полного охвата всех нормативных актов не гарантирует. Очередь страниц и документов сохраняется между запусками.

HTTPS-запросы GitHub проходят через российский SSH-релей на VPS владельца. Настройка — в deploy/README.md. Секреты SSH находятся в GitHub Secrets, браузер их не получает. Релей доступен только через SSH и не является публичным прокси. Недоступность или перегрузку самого ведомственного сайта это соединение не устраняет.

В «Источниках» показаны результат последней проверки, происхождение соединения, очередь и ошибки. «Частичный сбор» означает, что остались страницы/документы в очереди или были отдельные ошибки. Зелёный workflow подтверждает выполнение программы, но не доступность каждого сайта.

Для заранее сохранённых файлов ТФОМС доступна кнопка «Скачать копию». Предел одного файла — 20 МБ, всех текущих копий — 60 МБ; копия есть не для каждого документа. Остальные ссылки открывают официальный источник. Если ведомственный сайт требует российские сертификаты, используйте поддерживающий их браузер, например Яндекс. Сайт не может переключить браузер автоматически. Сверяйте значимые документы с оригиналом.

## Развёртывание и проверка

Settings → Pages → Source: **GitHub Actions**. Публикация и сбор запускаются при изменении main, по расписанию и вручную. Состояние SQLite сохраняется в отдельной ветке medpravo-state. Изменение репозитория требует перенастройки Pages, секрета/переменной релея и адреса workflow.

Python 3.12+, Node для проверки браузерного клиента. PDF-парсер закреплён по версии и SHA-256:

```sh
python -m pip install --require-hashes --no-deps -r requirements.txt
python -m unittest discover -s tests -p 'test_*.py'
node tests/test_github_client.js
python github_collect.py --export-only
```

github_collect.py создаёт site/data.json и статический сайт. HTTP-кэш и персональные отметки не попадают в сохранённую историю. Повреждённое состояние останавливает запуск. Actions закреплены по SHA; pull_request_target не используется. Лента и код публичны: не добавляйте данные пациентов, пароли и закрытые документы.
