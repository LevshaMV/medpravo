# МедПраво — публикации для центра «Евромед» в Калуге

Сайт размещается в GitHub Pages этого репозитория. Актуальный адрес указан в **Settings → Pages**. Инструкция находится в разделе «Как пользоваться» на самом сайте.

Федеральные и местные документы по работе медицинского центра: ОМС, МРТ/КТ, дети, наркоз, дневной стационар, забор анализов. Общие трудовые и налоговые нормы без специальной связи с медициной исключаются из основной подборки. Нормы для медорганизаций и медработников сохраняются. По ОМС охватываются тарифы и допсоглашения, госгарантии, объёмы, оплата, экспертизы, санкции, реестры, отчётность и финансирование помощи. Письма, проекты, тарифные соглашения и клинические рекомендации имеют собственные категории. Платные базы и API ChatGPT не используются.

## Добавление и хранение документов

Лента содержит документы **с 1 октября 2026 года включительно**. Используется дата публикации официального источника; по уточнению владельца при её отсутствии допускается подтверждённая дата самого акта. В карточке они подписываются отдельно: «публикация» / «дата акта». Для проектов Госдумы отдельно показывается дата регистрации законопроекта. Более ранние и недатированные записи исключаются из текущей ленты. Дата компьютера, файла, вступления в силу и обнаружения не доказывают новизну. При противоречивых публикационных датах запись не добавляется.

Для записей, прошедших этот порог, срок хранения и предел количества сейчас не заданы. Один URL не создаёт повторную публикацию. Собираются отдельные новые акты о внесении изменений; замена содержимого старого файла по прежнему URL не отслеживается. История Git может сохранять прежние версии состояния.

Дата берётся из карточки, страницы, API либо заголовка/текста самого акта. Дата упомянутого предшествующего соглашения не считается датой нового допсоглашения. «Как подтверждена дата» показывает основание и ссылку. Пределы чтения: файл до 20 МБ, первые 30 страниц текстового PDF, до 60 000 сохранённых символов и до 6 000 в публичном фрагменте. На GitHub первые две страницы сканов распознаются бесплатными Tesseract/Poppler (rus+eng); OCR помечается и может ошибаться. ZIP/RAR и защищённые файлы не распаковываются для чтения. Текст помогает отбору, но результат не является юридическим заключением.

По умолчанию показана подборка «По темам центра». Варианты «Проверить вручную» и «Все собранные документы» доступны в фильтре. Отбор учитывает заголовок и доступный извлечённый текст; название ведомства само по себе не считается медицинской темой. Исходный заголовок, основание отбора и качество текста можно раскрыть в карточке. Отметки просмотра хранятся только в текущем браузере.

## Обновление и время последнего сбора

GitHub Actions запускает сбор примерно в **03:17, 09:17, 15:17 и 21:17 по Москве**. GitHub может задержать или пропустить плановый запуск. После длительного отсутствия активности расписание публичного репозитория может отключиться: проверяйте Actions.

Блок «Последний завершённый сбор» показывает фактическое время завершения последней проверки источников по Москве, включая секунды. Это не время открытия сайта и не дата самого нового документа. Новый сбор может не найти новых подходящих публикаций. Обновление открытой страницы каждые 30 секунд только получает уже опубликованную ленту.

Ручной сбор: «Запустить на GitHub» → **Run workflow** → **Run workflow**. Нужен вход в аккаунт владельца. Для сбора свежих документов оставьте «Только переопубликовать» выключенным. После успешного окончания откройте или обновите сайт. Компьютер владельца и Docker для опубликованной версии не нужны.

## Ежедневная ИИ-сводка

В **18:00 МСК** GitHub Actions запускает открытую **Qwen3 4B** (Apache 2.0) и публикует результат в разделе «ИИ-сводки». Подготовка занимает несколько минут; очереди GitHub могут задерживать старт. Используется стандартный бесплатный вычислитель публичного репозитория. Платные API, API ChatGPT, облачные модели Ollama и платные вычислители не подключены. На компьютере владельца ничего устанавливать не требуется.

В отчёт входят новые найденные публикации по профилю центра с прошлого завершённого отчёта, а также неясные документы ОМС. Новизна акта по-прежнему определяется подтверждённой датой источника с 01.10.2026; дата обнаружения используется только для периода отчёта. ОМС анализируется первым. ИИ получает название и доступный фрагмент, его ответ проверяется по структуре, идентификаторам и дословным цитатам. Применимость и сроки нужно сверять с оригиналом. Проекты не являются действующими законами.

Результаты хранятся в `digests.json` ветки `medpravo-state` за последние 90 дат. Повторный сбой не удаляет готовый отчёт, незавершённые документы сохраняются для следующих попыток. День без новых документов не вызывает модель. До 18:00 ручной запуск создаёт предварительную сводку. В форме **Run workflow** для ручного отчёта включите «Только переопубликовать» и «Сформировать ИИ-сводку».

Исполнение ограничено 35 минутами, 60 попытками и двумя документами в запросе. Ollama и Actions закреплены по версии/SHA, модель — по SHA-256 манифеста. Модель слушает только `127.0.0.1` внутри временного вычислителя, без токенов; веса сохраняются в кэше Actions. Источники: [Qwen3 4B](https://huggingface.co/Qwen/Qwen3-4B), [Ollama](https://docs.ollama.com/api/chat).

## Источники и доступ

Все 26 источников включены. Для ГРЛС и Госдумы есть отдельные адаптеры карточек, для проектов НПА и клинических рекомендаций — API. Портал официального опубликования проверяется по 13 запросам с 01.10.2026: федеральные законы, Минздрав, ФФОМС, Росздравнадзор, санитарные акты, правительство, президент и калужские органы. ТФОМС проверяется по текущим нормативным разделам и разделам системы ОМС; ФФОМС — по четырём профильным каталогам. Проверяются все стартовые разделы и продолжается сохранённая очередь; при ограничении времени разделы ротируются. Известные недатированные ответы не скачиваются заново каждый запуск, но повторно проверяются через сутки. Полный охват и доступность всех ведомственных сайтов не гарантируются.

HTTPS-запросы GitHub проходят через российский SSH-релей на VPS владельца. Настройка — в deploy/README.md. Секреты SSH находятся в GitHub Secrets, браузер их не получает. Релей доступен только через SSH и не является публичным прокси. Недоступность или перегрузку самого ведомственного сайта это соединение не устраняет.

В «Источниках» показаны результат последней проверки, происхождение соединения, очередь и ошибки. «Частичный сбор» означает, что остались страницы/документы в очереди или были отдельные ошибки. Зелёный workflow подтверждает выполнение программы, но не доступность каждого сайта.

Для заранее сохранённых файлов ТФОМС доступна кнопка «Скачать копию». Предел одного файла — 20 МБ, всех текущих копий — 60 МБ; копия есть не для каждого документа. Остальные ссылки открывают официальный источник. Если ведомственный сайт требует российские сертификаты, используйте поддерживающий их браузер, например Яндекс. Сайт не может переключить браузер автоматически. Сверяйте значимые документы с оригиналом.

## Развёртывание и проверка

Settings → Pages → Source: **GitHub Actions**. Публикация и сбор запускаются при изменении main, по расписанию и вручную. Состояние SQLite сохраняется в отдельной ветке medpravo-state. При переносе владения репозиторием GitHub сохраняет историю и секреты; после принятия переноса проверьте Pages и выполните обычный полный сбор. Адрес workflow формируется из GITHUB_REPOSITORY автоматически. При копировании в новый репозиторий переменную и секреты релея нужно добавить заново. Отметки прочитанного хранятся в браузере и не переносятся на другой адрес сайта автоматически.

Python 3.12+, Node для проверки браузерного клиента. PDF-парсер закреплён по версии и SHA-256:

```sh
python -m pip install --require-hashes --no-deps -r requirements.txt
python -m unittest discover -s tests -p 'test_*.py'
node tests/test_github_client.js
python github_collect.py --export-only
```

github_collect.py создаёт site/data.json и статический сайт. HTTP-кэш и персональные отметки не попадают в сохранённую историю. Повреждённое состояние останавливает запуск. Actions закреплены по SHA; pull_request_target не используется. Лента и код публичны: не добавляйте данные пациентов, пароли и закрытые документы.
